# GoBeTerm Updates

Repositório público de distribuição de instaladores e atualizações do GoBeTerm para Windows x86_64.

O código-fonte do aplicativo permanece em um repositório privado separado. Este repositório contém somente documentação e arquivos de distribuição aprovados.

## Downloads

Consulte as [Releases](https://github.com/wedervieira/GoBeTerm-Updates/releases) para verificar os pacotes disponíveis e suas notas.

Versões **PREVIEW / NÃO HOMOLOGADO** são prévias de avaliação. Essa classificação não representa uma versão estável homologada.

## Atualizações no aplicativo

- Não é necessário fornecer PAT, token ou autenticação GitHub para consultar e baixar atualizações públicas.
- A verificação automática vem ativada e pode ser desativada nas configurações.
- O download e a instalação dependem da ação do usuário; a instalação solicita confirmação para reiniciar o aplicativo.
- Os pacotes de atualização têm assinatura Tauri, verificada pelo aplicativo antes da instalação.
